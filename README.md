# shirt_maker
📁 1. ไฟล์ ⁠config.py⁠ (การตั้งค่าโฟลเดอร์)
ไฟล์นี้ใช้สำหรับเปลี่ยนชื่อโฟลเดอร์หลัก ถ้าในอนาคตคุณอยากเปลี่ยนชื่อโฟลเดอร์ ไม่ต้องไปแก้โค้ดลึกๆ ให้มาแก้ที่นี่ที่เดียวครับ
 ⁠BASE_DIR = "shirts"⁠ : ถ้าอยากเปลี่ยนชื่อโฟลเดอร์เก็บเสื้อผ้า (เช่น เป็น ⁠my_products⁠) ให้แก้ตรงนี้
 ⁠OUTPUT_DIR = "outputs"⁠ : ถ้าอยากเปลี่ยนชื่อโฟลเดอร์ที่ใช้ออกวิดีโอ (เช่น เป็น ⁠done_videos⁠) ให้แก้ตรงนี้
 ⁠SUBFOLDERS = ["ฮุก", "โชว์แบบธรรมดา", "โชว์แบบเร็ว", "ปิดท้าย"]⁠ : ถ้าอยากเปลี่ยนชื่อโฟลเดอร์ย่อยข้างใน ต้องมาแก้ให้ตรงกันตรงนี้ครับ
📁 2. ไฟล์ ⁠planner.py⁠ (ปรับความยาว/จำนวนคลิปที่จะสุ่ม)
ไฟล์นี้คือสมองส่วนที่สุ่มเลือกคลิป ถ้าคุณรู้สึกว่าวิดีโอที่ออกมา ยาวเกินไป หรือ สั้นเกินไป ให้มาแก้ตัวเลขในไฟล์นี้ ตรงส่วนที่เขียนว่า ⁠mode == 1⁠, ⁠mode == 2⁠, ⁠mode == 3⁠:
 โหมด 1 (ธรรมดาล้วน):
⁠count = min(random.randint(8, 10), ...)⁠
(หมายความว่า: สุ่มหยิบคลิปโชว์ธรรมดา 8 ถึง 10 คลิป -> ปรับเพิ่ม/ลดตัวเลขนี้ได้)
 โหมด 2 (เร็วล้วน):
⁠count = min(random.randint(11, 18), ...)⁠
(หมายความว่า: สุ่มหยิบคลิปโชว์เร็ว 11 ถึง 18 คลิป -> ปรับเพิ่ม/ลดได้)
 โหมด 3 (ผสม):
⁠c_normal = min(random.randint(2, 5), ...)⁠ (หยิบธรรมดา 2-5 คลิป)
⁠c_fast = min(random.randint(4, 7), ...)⁠ (หยิบเร็ว 4-7 คลิป)
📁 3. ไฟล์ ⁠effects.py⁠ (ปรับความแรงการซูม)
ถ้าในอนาคตรู้สึกว่าภาพซูมน้อยไปจนมองไม่เห็น หรือซูมแรงไปจนเวียนหัว/ภาพแตก ให้มาแก้ที่ฟังก์ชัน ⁠get_zoom_level⁠
 ⁠return 0.05⁠ คือ ซูม 5%
 ⁠return random.uniform(0.08, 0.10)⁠ คือ สุ่มซูมระหว่าง 8% - 10%
(คำแนะนำ: วิดีโอแนวตั้งแบบ Reels/TikTok ค่าซูมที่สวยและไม่ทำให้ภาพแตก มักจะไม่เกิน 0.15 หรือ 15% ครับ)
📁 4. ไฟล์ ⁠builder.py⁠ (ตั้งค่าสเปควิดีโอและคุณภาพภาพ)
ไฟล์นี้คือห้องเครื่องหลัก ถ้าอยากอัปเกรดความคมชัด หรือความลื่นไหล ให้มาแก้ตัวแปรเหล่านี้ครับ (อยู่ช่วงกลางๆ ไฟล์):
 ปรับความละเอียดและเฟรมเรต:
 ⁠fps = 30⁠ : ถ้าต้นฉบับคุณถ่ายมาแบบ 60fps อยากให้คลิปลื่นๆ ปรับเป็น ⁠60⁠ ได้เลยครับ
 ⁠w = 720⁠, ⁠h = 1280⁠ : นี่คือขนาด 720p (9:16) ถ้าอยากได้ระดับ Full HD 1080p ให้แก้เป็น ⁠w = 1080⁠, ⁠h = 1920⁠ (แต่คอมจะใช้เวลาเรนเดอร์นานขึ้น)
 ปรับความเร็วทรานซิชัน (ตอนเปลี่ยนภาพ):
 ⁠trans_dur = 0.3⁠ : คือ 0.3 วินาที ถ้าอยากให้เอฟเฟกต์ระหว่างฮุกกับท่อนโชว์มันค่อยๆ เฟดช้าๆ นุ่มๆ ให้แก้เป็น ⁠0.5⁠ หรือ ⁠1.0⁠
 ปรับความคมชัด (เพื่อสู้กับภาพแตก):
 ⁠unsharp=3:3:0.5⁠ : ตัวทำภาพคมชัด ถ้าภาพมันดูคมจนหลอกตา แข็งเกินไป ให้ลดเลข ⁠0.5⁠ ลงมาเป็น ⁠0.3⁠ หรือ ⁠0.2⁠
 ปรับขนาดไฟล์และคุณภาพ (บรรทัด ⁠-crf⁠ ด้านล่างสุด):
 ⁠"-crf", "23"⁠ : ค่าความคมชัดวิดีโอ (ค่าน้อย = ยิ่งชัดแต่ไฟล์ใหญ่)
 18 = ชัดกริ๊บ (ไฟล์ใหญ่มาก)
 23 = มาตรฐาน (สมดุล)
 28 = ชัดน้อยลง (ไฟล์เล็กส่งง่าย)
